02 — The full Agentic AI OS

Six agents, one deterministic command path, everything on-site

The boundary is the argument. Everything inside the cyan dashed box is deterministic — rules, thresholds and a fixed whitelist. The one generative component (XAI, violet) sits outside it, reads the audit log, and writes text for a human. A hallucinated or injected command has no path to an actuator, because no free-text-to-command step exists anywhere in the system.

04 — Decision logic

Two states, one shed ladder, one rule that can never be crossed

Why the barrier matters. The shed ladder climbs from P4 upward as energy tightens — and physically stops below P1. The rule lives in the Validator, not the Planner, so even a fully compromised Planner cannot switch off the fridge. Safety is enforced at the gate, never trusted at the source.

06 — Closing the loop

What "learn" actually means here — and what it is forbidden to touch

The learn step

  • Baselines recalibrate. Rolling per-device statistics sharpen outlier detection; adjacent-node cross-checks catch slow sensor drift.
  • Forecast error corrects. Predicted vs. actual SoC decay adjusts the discharge model, so depletion estimates improve every outage.
  • Threat memory persists. Patterns from a quarantined node are retained by the Security agent and matched against future traffic.
  • Operator overrides are studied. Every manual override is logged with its reason and reviewed between runs — human-approved, never auto-applied.

The immutability guardrail

Learning updates estimates only. It can never modify:

  • the command whitelist
  • the 4-tier priority hierarchy
  • the NEVER_SHED rule
  • the RBAC permission matrix

Those are immutable constants, changeable only by a signed configuration change under admin RBAC — never by the running system. An adaptive controller that could re-learn its own safety limits is exactly the failure mode we designed out.
